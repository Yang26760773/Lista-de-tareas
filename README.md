# Lista de tareas
## ¿En qué consiste el proyecto y cuál es su objetivo?

Este proyecto consiste en desarrollar una lista de tareas que permita al usuario registrar, consultar y marcar como realizadas las actividades que necesita completar. Su objetivo es aplicar conocimientos básicos de programación mediante la creación de una herramienta sencilla para organizar tareas.
